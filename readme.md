# Iris Shader Pack for Minecraft by Alex Nguyen and Gregory James

A custom Minecraft shader pack designed for use with the Iris Shaders mod. This shader pack adds real-time graphics effects such as improved lighting, shadows, ambient occlusion, fog, and post-processing effects to enhance Minecraft’s visual style while maintaining performance.

## Features

- Custom diffuse lighting
- Shadow mapping
- Screen-space ambient occlusion
- Distance fog
- Water effects

## Requirements

Before using this shader pack, make sure you have:

- Minecraft: Java Edition 1.17+.
- Fabric Loader
- Iris Shaders
- Sodium, recommended for better performance

You can install Iris from the official Iris Shaders website.

## Installation

Heres a video tutorial as well https://youtu.be/cdREyi4UId4?si=GHJ0SEhnP2_cyYV3

1. Download or copy this shader pack folder.
2. Open Minecraft with the Iris/Fabric profile.
3. From the Minecraft main menu, go to:

   `Options > Video Settings > Shader Packs`

4. Click `Open Shader Pack Folder`.
5. Place this shader pack as a `.zip` file into the shaderpacks folder.
6. Return to Minecraft.
7. Select the shader pack from the list.
8. Click `Apply`.

## How to Use

Once the shader pack is enabled, load into a world to see the visual effects. The shader pack modifies how lighting, shadows, fog, water, and screen-space effects are rendered.

For best results:

- Use a reasonably modern GPU.
- Lower render distance if performance is low.
